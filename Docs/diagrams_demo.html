4. Lược đồ Cơ sở dữ liệu (ER Diagram)

Lược đồ cốt lõi bao gồm User, Khu trọ, Hợp đồng thông minh và Hóa đơn thanh toán.

erDiagram USERS ||--o{ PROPERTIES : manages USERS ||--o{ ROOMS : rents USERS ||--o{ CONTRACTS : signs USERS ||--o{ REVIEWS : writes PROPERTIES ||--o{ ROOMS : contains PROPERTIES }|--|| LOCATIONS : located_at ROOMS ||--o{ CONTRACTS : belongs_to ROOMS ||--o{ ROOM_MEDIA : has CONTRACTS ||--o{ INVOICES : generates CONTRACTS ||--o{ TRANSACTIONS : tracks USERS { UUID id PK string phone string password string cccd_number string wallet_address enum role "LANDLORD, TENANT, ADMIN" enum kyc_status "PENDING, VERIFIED, REJECTED" } PROPERTIES { UUID id PK UUID landlord_id FK string title string description string address json amenities enum status "PENDING, APPROVED, REJECTED" boolean is_safe_content } LOCATIONS { UUID id PK UUID property_id FK float latitude float longitude string province string district string ward } ROOMS { UUID id PK UUID property_id FK string room_number decimal price float area enum status "AVAILABLE, RENTED, MAINTENANCE" } CONTRACTS { UUID id PK UUID tenant_id FK UUID room_id FK decimal deposit_amount date start_date date end_date string smart_contract_address enum status "ACTIVE, TERMINATED, EXPIRED" } INVOICES { UUID id PK UUID contract_id FK decimal total_amount date due_date enum status "UNPAID, PAID, OVERDUE" } TRANSACTIONS { UUID id PK UUID invoice_id FK string tx_hash string wallet_from string wallet_to decimal amount_crypto timestamp created_at }
